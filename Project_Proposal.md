# Project Proposal: Recello E-Commerce / Buyback Platform

## 1. Project Overview

Recello is a custom device resale and buyback platform designed to provide a smooth end-to-end customer journey from product discovery to quote generation, order placement, and pickup scheduling.

The system covers the complete workflow:

**Customer → Website → Quote/Evaluation → Login → Checkout → Pickup Scheduling → Orders/Support**

It also includes the required frontend and backend support for admin-side operations and future Ionic mobile app expansion.

## 4. Project Flow Summary

### User Journey
1. User opens the website.
2. User browses services or device categories.
3. User selects brand, model, and variant.
4. User answers evaluation questions.
5. The system calculates the price.
6. User logs in if required.
7. User completes checkout.
8. User selects address and pickup slot.
9. Request is submitted and shown in orders.

### Admin / Backend Support Flow
1. Admin manages catalog data.
2. Admin manages questions, banners, FAQs, and contact requests.
3. Admin tracks leads and sell listings.
4. Admin can support future merchant/agent operations.

### Future Ionic Mobile Flow
1. Login
2. Device selection
3. Evaluation
4. Quote generation
5. Pickup scheduling
6. Orders / support
